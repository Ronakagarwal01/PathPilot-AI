Path Pilot 🚀

An AI-powered career preparation and learning platform designed to help students and job seekers prepare for placements, aptitude rounds, coding tests, interviews, and career growth — all in one place.


📌 Overview

Path Pilot is a modern EdTech + Career Guidance platform built to simplify the journey from learning to employment. The platform provides students with smart tools for:

Aptitude preparation
Mock interviews
Coding practice
Resume building
Career tracking
Progress analytics
AI-based learning assistance

The goal of the project is to create a centralized system where students can improve their technical, logical, and communication skills before placements and interviews.
